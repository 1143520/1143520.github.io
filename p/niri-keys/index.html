niri 快捷键图解：13 张图看懂列、工作区与布局

把 niri 的 104 个快捷键画成示意图：列与窗口的关系、塞入踢出、列宽、标签叠放、工作区、逃生键与截图，一页一图对照记

阅读时长: 3 分钟
字数: 1223字
   
文章摘要
摘要小助理今天溜号啦……😜

niri 的键位有一百多条，光看配置文件记不住。我把它们画成了图：每个动作一张示意，配合键位表，看一遍就知道按下去会发生什么。

下图全部按本机实际配置绘制（~/.config/niri/cfg/keybinds.kdl，104 条绑定），不是通用示例。

一、先记住三个键

按键作用什么时候用
Mod + Shift + Esc弹出快捷键浮层忘了哪个键干什么，随时查
Mod + Esc解除按键抑制全屏程序吃掉所有快捷键时救场
Mod + Z概览模式窗口多了找不到，一眼看全

Mod 键就是 Super 键，多数键盘印着 Windows 图标。

二、列才是基本单位

niri 和别的平铺窗口管理器最大的不同：窗口按列组织。一列可以放一个或多个窗口，列从左到右排，列内的窗口上下排。

把列想成书架上的一摞书——横向移动是换一摞，纵向移动是翻同一摞里的书。

按键作用
Mod + ←/→（或 H/L）在列之间移动
Mod + ↑/↓（或 K/J）在列内窗口之间移动
Mod + Ctrl + ←/→把整列移到左边/右边
Mod + Ctrl + ↑/↓把窗口在列内上下移动
Mod + Home/End跳到第一列 / 最后一列

三、把窗口塞进同一列

两个窗口想并成一组，不用拖鼠标，用「塞入」和「踢出」。

按键作用
Mod + ,把当前窗口塞进左边那一列
Mod + .把当前窗口从列里踢出
Mod + [吞并左边一列
Mod + ]把当前列弹出，与右列分开

这两个键掌握之后，niri 的布局才算真正会用——很多人觉得 niri 「窗口只能并排」，就是没塞过。

四、调宽度与叠放

按键作用
Mod + - / Mod + =列宽 −10% / +10%
Mod + Shift + -/=窗口高度 −10% / +10%
Mod + C当前列居中（Mod+Ctrl+C 全部居中）
Mod + W列内切换标签式叠放
Mod + T窗口浮动

五、工作区

工作区是纵向的，卷动切换，每个工作区有自己的一套列。

按键作用
Mod + 1~9切到对应工作区
Mod + Ctrl + 1~9把当前列送到对应工作区
Mod + Tab回到上一个工作区
Mod + M伪最小化：丢到「桌面」工作区
Mod + Shift + M切到「桌面」找回来

Mod + M 那个「伪最小化」值得单独说：niri 没有真正的最小化，点应用自绘的最小化按钮可能让界面卡住，所以用把它挪走的方式代替。

六、应急与截图

全屏程序吃掉按键是常见事故，Mod + Esc 是唯一的逃生口。

按键作用
Ctrl + Shift + 1区域截图
Ctrl + Shift + 2整屏截图
Ctrl + Shift + 3当前窗口截图
XF86 音量/播放键音量、静音、上一首、下一首

七、滚轮与窗口太多

方向键记不住没关系，滚轮基本能覆盖大部分移动。

八、常用应用与改键位

按键作用
Mod + Return终端（Ghostty）
Mod + Ctrl + Return应用启动器
Mod + BFirefox
Mod + E文件管理器
Mod + A控制中心（音量、亮度、蓝牙）
Mod + V剪贴板历史
Mod + Shift + Q电源菜单
Mod + Alt + L锁屏
Mod + Shift + ZKando 饼状菜单

改键位只要编辑 ~/.config/niri/cfg/keybinds.kdl，保存后 niri 自动重载，不用重启。改完跑一次 niri validate 校验语法，避免写错导致整段不生效。

九、三个容易踩的点

  1. niri 没有真正的最小化，Mod + M 只是把窗口挪到「桌面」工作区
  2. 列是核心概念，不塞窗口就只是并排，Mod + , 才会出现叠放效果
  3. Mod + Esc 一定要记住，全屏应用吃掉按键时它是唯一退路

以上键位对应本机 niri 26.04 + noctalia 5.3 的实际配置，换机器或换配置后请以 Mod + Shift + Esc 浮层显示为准。
