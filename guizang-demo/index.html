01原来是手拼字符串

手写 SVG 的每一行都要记住三件事：属性顺序、路径长度、CSS 变量怎么塞。路径动画要算 stroke-dasharray，那个长度得用 math.hypot 自己求。

def line(self, x1, y1, x2, y2, w=3):
    L = math.hypot(x2 - x1, y2 - y1)
    self.p.append(
        f'<path class="gw" style="--len:{L:.1f}"'
        f'd="M{x1} {y1} L{x2} {y2}" stroke-dashoffset="{L:.1f}"/>')

嵌套引号多了眼睛会花，打错属性名浏览器直接忽略——你只会看到"那个东西没出来"，没有报错。

02DrawSVG 的写法

同一个圆，一行：

d.append(dw.Circle(cx, cy, r, fill="none", stroke=col, stroke_width=sw))

差别在三点：

  • 不用拼字符串——属性是关键字参数，写错直接 TypeError
  • 不用记 SVG 语法——stroke-width 写成 stroke_width，下划线自动转连字符
  • 元素可以复用——Drawing 能 append 到另一个 Drawing 里

03它替你算的几何

几何辅助方法覆盖了路径指令的常用部分：

dw.Path(stroke="#000", fill="none")
  .M(x, y).L(x2, y2)                     # 折线
  .Q(cx, cy, x, y)                       # 二次贝塞尔
  .C(cx1, cy1, cx2, cy2, x, y)           # 三次贝塞尔
  .A(rx, ry, rot, arc, sweep, x, y)      # 圆弧

手写时这些 d 属性全得自己拼，参数顺序记错只能去查 MDN。

DrawSVG 的动画路线是逐帧渲染，不是 CSS 动画。as_animation_frames(frames=60) 出来的是 60 张位图。七千像素的长图逐帧渲染不划算，滚动触发更是运行时行为，没法逐帧做。

05两个真实的坑

一、count() 不是无参的

d.count() 报 TypeError，要总数得 len(list(d.all_elements()))。

二、class 参数是 class_

Python 关键字冲突，写 class= 直接 SyntaxError。

06最后怎么用的

画图      DrawSVG（省掉字符串拼接）
动画      CSS transition（手写）
触发      IntersectionObserver（手写）
部署      单文件 HTML（不上构建链）

DrawSVG 解决"怎么把图形描述成代码"，不解决"怎么让它在浏览器里动起来"。值得用，但别指望它替你解决触发和时序。
